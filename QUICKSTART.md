# 🎯 FEMFUR IMAGEBOARD - QUICK START

## 📦 Что в этом архиве?

Полностью рабочий имиджборд на Vanilla JavaScript + Supabase.

### ✅ Что уже реализовано:

**Основной функционал:**
- ✅ Анонимные посты (без регистрации)
- ✅ Регистрация пользователей (опционально)
- ✅ Hash-based профили (/u/hash)
- ✅ 40+ бордов (разделены по категориям)
- ✅ Создание тредов с изображениями
- ✅ Ответы в тредах с изображениями
- ✅ Цитирование постов (>>number)
- ✅ Auto-bump (новые ответы поднимают тред)
- ✅ Счетчик просмотров (уникальные)
- ✅ Sticky threads (закрепленные треды)

**Дополнительные фичи:**
- ✅ Мультиязычность (EN/UK/RU)
- ✅ Thread of the Day
- ✅ Thread of the Week
- ✅ Recent Threads виджет
- ✅ Страницы профилей с историей постов
- ✅ Анонимный режим для зарегистрированных
- ✅ Responsive дизайн (мобильная версия)

## 🚀 Быстрый старт (5 минут)

### Шаг 1: Создайте Supabase проект
1. Зайдите на [supabase.com](https://supabase.com)
2. Создайте новый проект
3. Запустите SQL из файла `database_schema.sql`

### Шаг 2: Настройте Storage
1. Создайте bucket `image` (публичный)
2. Добавьте политики для чтения и записи

### Шаг 3: Настройте код
1. Откройте `js/supabaseClient.js`
2. Вставьте свои SUPABASE_URL и SUPABASE_ANON_KEY

### Шаг 4: Деплой
1. Загрузите все файлы на GitHub
2. Включите GitHub Pages
3. Готово! ✨

**Подробная инструкция**: читайте `SETUP.md`

## ⚙️ Что нужно настроить?

### Обязательно:
1. ✅ `js/supabaseClient.js` - вставьте ваши ключи Supabase
2. ✅ Создайте таблицы в Supabase (используйте `database_schema.sql`)
3. ✅ Создайте bucket `image` в Supabase Storage
4. ✅ Создайте `assets/fav.png` (иконка сайта)

### Опционально:
- Измените название "Femfur" на своё
- Настройте цветовую схему в CSS
- Добавьте/удалите борды
- Добавьте новые языки

## 🗄️ База данных

### Таблицы:
1. **users** - пользователи (nickname, password_hash, avatar, status)
2. **threads** - треды (board, title, content, image, views, sticky)
3. **replies** - ответы (thread_id, content, image, user_id)

### Индексы:
- Оптимизированы для быстрой работы с тысячами постов
- Автоматический bump при новых ответах
- Триггеры для обновления времени

Полная схема в файле `database_schema.sql`

## 🌍 Мультиязычность

Поддерживает:
- 🇬🇧 English
- 🇺🇦 Українська
- 🇷🇺 Русский

Добавить новый язык:
1. Скопируйте `locales/en.json`
2. Переведите все строки
3. Добавьте в `<select id="langSelect">`

## 🎨 Кастомизация

### Изменить название:
В `index.html`:
```html
<h1><a href="/" id="logo">Ваше Название</a></h1>
```

### Изменить цвета:
В `css/style.css` найдите:
```css
background-color: #eef2ff;  /* Фон */
color: #af0a0f;             /* Акцент */
```

### Добавить борду:
В `js/boards.js`:
```javascript
myboard: { name: '/my/', title: 'My Board', category: 'Custom' }
```

## 🔒 Безопасность

⚠️ **Важно для продакшена:**

Текущая реализация - это MVP. Для продакшена нужно добавить:

1. **Server-side валидация** - все проверки на клиенте можно обойти
2. **Proper password hashing** - используйте Argon2/bcrypt на сервере
3. **Rate limiting** - защита от спама
4. **Модерация** - админ-панель для удаления контента
5. **Captcha** - защита от ботов
6. **Content filtering** - проверка изображений

Подробнее в `ARCHITECTURE.md`
